# Pempek — Makanan Nusantara

Website project yang fokus khusus pada **Pempek khas Palembang**.

## Halaman
- Beranda
- Tentang Pempek
- Menu Pempek
- Pesan Pempek

## Fitur
- Responsive untuk desktop dan mobile
- Navigasi antarhalaman
- Menu pempek
- Keranjang sederhana menggunakan localStorage
- Form simulasi pemesanan
- Tampilan modern

Project ini dibuat sebagai website frontend statis untuk tugas Makanan Nusantara.
